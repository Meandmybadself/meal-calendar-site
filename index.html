Eisenhower Elementary Lunch Calendar

Stay informed about daily lunch options at Eisenhower Elementary School in Hopkins, MN. This calendar is automatically updated with the latest meal information, so you'll always know what's on the menu.

Download ICS File

Add to Google Calendar

  1. Copy the calendar URL:
    https://mealcal.meandmybadself.com/EisenhowerElementaryMN-Lunch-menu.ics
  2. Open Google Calendar.
  3. Under "Other calendars" click + and choose From URL.
  4. Paste the URL and click Add calendar.

Add to Apple Calendar (macOS)

  1. Copy the calendar URL:
    https://mealcal.meandmybadself.com/EisenhowerElementaryMN-Lunch-menu.ics
  2. Open the Calendar app.
  3. Select File > New Calendar Subscription.
  4. Paste the URL and click Subscribe.

Add to iPhone or iPad

  1. Copy the calendar URL:
    https://mealcal.meandmybadself.com/EisenhowerElementaryMN-Lunch-menu.ics
  2. Open Settings > Calendar > Accounts > Add Subscribed Calendar.
  3. Paste the URL and tap Next, then Save.

Manual Download

If your calendar app doesn't support subscriptions, download the ICS file and import it into your calendar of choice.

Calendar data updates automatically from the Eisenhower lunch menu.
